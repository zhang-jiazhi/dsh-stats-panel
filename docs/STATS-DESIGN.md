# Token 统计控制台

2026-09-13：按用户最新反馈采用石墨暗色，替代此前的暖白编辑式方案。保留高信息密度、低饱和蓝色数据强调与插件自身的滚动容器，不修改 DSH 外层主题。

## 视觉与信息结构

- 背景 `#10141b`，卡片 `#181e28`，内嵌表面 `#1e2734`；正文 `#e5ebf4`、辅文 `#b6c1d2` / `#929fb2`，强调色 `#91b0ed`。输入框、选择器、提示浮层、加载骨架与异常卡同步暗色，原生控件使用 `color-scheme: dark`。
- 不等宽总览：蓝黑累计用量区搭配四项紧凑指标，包含输入、输出、缓存构成；数字采用本机 Avenir Next / DIN Alternate，模型标识使用等宽字体，不加载外部字体或新增生产依赖。
- 趋势和分布双栏：天 / 周 / 月分桶，Token / 调用次数切换；分布可切换模型 / 渠道。保留键盘可聚焦的图表提示，遵从减少动画偏好。
- 渠道余额采用紧凑网格，默认六项，可展开全部或筛选待处理渠道。查询错误保留完整详情；手动额度本机覆盖值在保存、刷新后即时回显。
- 明细支持多关键词搜索、按用量或调用数排序、分页及 CSV 导出。模型、渠道和价格每页八项，最近调用每页十项；价格编辑草稿跨分页保留。
- 响应式按插件容器宽度而非整个窗口切换；极窄屏明细标签使用两列，避免侧栏占位造成溢出。

信息组织参考 [CC Switch 用量统计](https://cc-switch.cc/en/tutorials/usage-statistics) 的指标、趋势与明细层级，以及 [Sub2API](https://github.com/Wei-Shaw/sub2api) 的多渠道聚合思路；未复用第三方代码或引入其依赖。

## 数据口径

- 总量仍为未命中输入 + 输出 + 缓存读 + 缓存写，未重复加入推理 Token。缓存命中率使用服务端返回值。
- 顶部指标与模型 / 渠道分布为累计口径，含归档。图表周期切换仅影响图表，明确显示首尾日期与有记录的周期数量；均值按有记录周期计算。
- 搜索与分页不改变模型 / 渠道占比的全量分母。调用记录仅展示服务端返回的最近记录，不冒充全部历史。
- 缺失价格显示“未计价”，不伪装成免费；已配置为零的套餐或免费模型继续显示零。费用仍按现有本机价格表估算，不改默认价格或账单口径。
- CSV 导出当前分类的全部搜索结果，不限于当前分页；保留精确数值，处理引号、换行及公式型模型名。
